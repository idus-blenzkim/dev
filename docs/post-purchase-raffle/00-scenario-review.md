# 구매 후 뽑기 시나리오 — 평가서

작성일: 2026-08-11
대상 시나리오:
> 2만원 이상 구매 시 뽑기 기회 1회 / 사은품 지급, 꽝 없음 / 고객이 결과를 보고 수령
> 여부 선택 / 수령 방식은 "다음 주문 때 동봉" 또는 "모아서 받기" 중 선택

## 총평

**아이디어의 방향은 맞고, 실행 설계는 현재 상태로 런칭 불가입니다.**

좋은 점은 명확합니다. 구매 직후는 고객이 브랜드에 가장 호의적인 순간이고, 그 순간에
"공짜로 하나 더"를 얹는 것은 재구매 유도로 검증된 패턴입니다. "다음 주문 때 동봉"은
그 자체로 재구매 훅이라 발상이 영리합니다.

문제는 이 시나리오가 **마케팅 문장으로는 완결돼 있지만 물류 문장으로는 한 줄도
정의되지 않았다**는 데 있습니다. 텐바이텐은 위탁 마켓플레이스이고 물류는 외부 대행
(플러스에이컴퍼니)이며 단가는 건당으로 청구됩니다. 이 구조에서 "사은품 하나 더 보내기"는
공짜가 아니라 **건당 1,600원 ~ 7,040원짜리 행위**입니다.

실측 단가표에 태워 계산한 결과, 원안 그대로 가면 **월 2,220만원**이 나가고 이를
회수하려면 **주문이 16.1% 늘어야** 합니다. 사은품 프로모션으로 두 자릿수 주문 상승은
현실적인 목표가 아닙니다.

그리고 타이밍 문제가 하나 더 있습니다. 오늘 기준 물류센터 이전 프로젝트가 Phase 4
(이전 실행) 한복판이고 안정화는 9월 둘째주까지입니다. 신규 SKU 카테고리와 신규 동봉
공정을 이 시기에 창고에 얹는 것은 이전 리스크를 직접 키웁니다.

**결론: 원안 기각. 아래 P0 5건을 해소한 축소안으로 재설계 후, 사전등록된 게이트를
통과할 때만 단계적으로 런칭.** 재설계안은 §4, 검증 플랜은 `01-validation-plan.md`.

## 1. P0 — 설계가 무너지는 결함 (해결 전 착수 불가)

### P0-1. "꽝은 없다" + "받을지 선택한다"는 논리적으로 모순

꽝이 없는데 고객이 왜 거절합니까. 거절하는 유일한 이유는 **나온 사은품이 마음에 안
들어서**입니다. 즉 이 설계는 꽝을 없앤 게 아니라, **꽝 판정을 회사에서 고객에게
넘긴 것**입니다.

결과적으로 운영 지표에 `거절률`이 생기고, 그 숫자가 곧 체감 꽝률이 됩니다. 거절률이
15%면 고객 여섯 중 한 명은 "꽝 없다더니 쓰레기 나왔다"를 경험합니다. "꽝 없음"을
전면에 내건 상태에서 이 경험은 브랜드에 마이너스입니다.

> **수정 방향**: "거절"이라는 선택지 자체를 없앨 것. 마음에 안 들면 **포인트로 전환**
> 하거나 **재뽑기 1회**를 주는 구조로 바꾸면, 고객은 항상 무언가를 얻고 "꽝 없음"이
> 문구가 아니라 사실이 됩니다.

### P0-2. "모아서 받기"는 단위경제가 성립하지 않음

실측 단가로 계산한, 사은품 1개를 고객 손에 전달하는 한계비용:

| 사은품 원가 | 다음 주문 동봉 | 모아서(1개 배송) | 모아서(3개씩) | 모아서(5개씩) |
|---:|---:|---:|---:|---:|
| 500원 | **1,600원** | **7,040원** | 2,747원 | 1,888원 |
| 1,000원 | 2,100원 | 7,540원 | 3,247원 | 2,388원 |
| 2,000원 | 3,100원 | 8,540원 | 4,247원 | 3,388원 |
| 3,000원 | 4,100원 | 9,540원 | 5,247원 | 4,388원 |

*근거: B2C 출고 2,940원/BOX + 정합작업 1,000원/세트 + 바코드 100원/UNIT (2025년
물류대행 단가표) + 택배비 2,500원(가정). 부가세 별도.*

**원가 500원짜리 사은품을 따로 부치면 7,040원이 나갑니다.** 사은품 값의 14배가 물류비
입니다. 배치를 5개까지 채워야 겨우 동봉 수준(1,888원)에 근접하는데, 고객이 5개를 모을
때까지 기다린다는 건 5번 더 구매한다는 뜻이라 애초에 "모아서 받기"가 필요 없습니다.

민감도 분석에서도 **사은품 원가보다 "모아서 받기 비율"이 총비용을 훨씬 크게 흔듭니다.**
모아받기 비율이 0%→80%로 가면 (원가 1,000원 기준) 월 1,040만원 → 3,240만원, 3배입니다.

> **수정 방향**: "모아서 받기" 삭제. 또는 **3개 이상 모였을 때만 신청 가능 + 배송비
> 고객 부담**을 조건으로 둘 것. 무조건적 무료 별도배송은 어떤 파라미터에서도 회수 불가.

### P0-3. 지급 트리거와 금액 기준이 정의되지 않음

"2만원 이상 구매 시"는 개발도 CS도 착수할 수 없는 문장입니다. 최소한 이 6개가
정해져야 합니다.

| 정의 필요 항목 | 선택지 | 트레이드오프 |
|---|---|---|
| 뽑기 발급 시점 | 결제완료 / 배송완료 / 구매확정 | 결제완료는 즉시성이 살지만 취소 어뷰징에 노출. 구매확정은 안전하지만 구매와 보상 사이가 멀어져 효과 급감 |
| 2만원 기준액 | 상품 정가 / 쿠폰·포인트 차감 후 실결제액 | 실결제액 기준이 방어적이나, 쿠폰 쓰면 못 받는다는 불만 발생 |
| 배송비 포함 여부 | 포함 / 제외 | 포함하면 배송비로 임계값 넘기는 편법 발생 |
| 부분 취소 시 | 회수 / 유지 | 2만원 → 1.5만원으로 떨어져도 뽑기를 유지할지 |
| 전체 취소·반품 시 | 회수 / 유지 | 회수 안 하면 "결제 후 취소" 무한 반복이 뚫림 |
| 1인 발급 상한 | 무제한 / 일 N회 / 월 N회 | 상한 없으면 분할 주문 유인이 그대로 비용이 됨 |

> **권장 조합**: 발급은 **결제완료 즉시**(도파민 유지), 실제 사은품 **확정·출고는
> 구매확정 이후**. 기준액은 **쿠폰/포인트 차감 후 실결제 상품금액, 배송비 제외**.
> 전체 취소 시 회수, 부분 취소로 2만원 미만이 되면 회수. **1인 월 5회 상한.**

### P0-4. "다음 주문 동봉"이 물리적으로 가능한 비율이 확인되지 않음

이게 시나리오 전체를 떠받치는 가정인데 아무도 확인하지 않았습니다.

텐바이텐은 **위탁 판매 마켓플레이스**입니다. 다음 주문이 판매자 직배송이면 포천
물류센터를 거치지 않으므로 **동봉 자체가 불가능**합니다. 동봉이 가능한 건 자사 물류센터
출고 건뿐입니다.

만약 자사 물류 출고 비중이 낮다면, "다음 주문에 동봉"을 약속해놓고 상당수 고객에게는
동봉할 방법이 없습니다. 그러면 전부 "모아서 별도 배송"으로 흘러가고, P0-2의 7,040원
경로로 직행합니다.

> **이건 첫 번째로 확인해야 할 숫자입니다.** 자사 물류 출고 비중이 낮으면 시나리오는
> 재설계가 아니라 폐기 대상입니다. (검증 플랜 Gate 0)

추가로, 동봉 실행에는 **출고 시점에 해당 회원의 미수령 사은품을 조회해 피킹리스트에
합류시키는 Webadmin 연동**이 필요합니다. 이건 플러스에이컴퍼니 시스템 개발 건이며,
현재 계약 단가표에 없는 신규 공정입니다. 단가 협의 대상입니다.

### P0-5. 물류센터 이전과 런칭 시점이 정면충돌

오늘은 2026-08-11입니다. 이전 프로젝트 일정상:

- Phase 4 (이전 실행, 재고 이동 / 병행 운영 / 구 센터 철수): **7월 셋째주 ~ 8월 둘째주 → 진행 중**
- Phase 5 (안정화, 오배송 대응): 8월 셋째주 ~ 9월 둘째주
- 이전 완료 목표: 2026년 9월

이 시나리오는 창고에 **신규 사은품 SKU 재고 + 신규 동봉 공정**을 추가합니다. 재고를
옮기는 중에 옮길 재고를 늘리고, 오배송 대응 기간에 오배송 확률이 높은 공정을 새로
붙이는 셈입니다.

> **권장: 런칭은 물류 안정화 완료(9월 둘째주) 이후.** 실질 최속 런칭은 **10월**입니다.
> 8~9월은 데이터 검증과 설계 확정에 쓰는 것이 오히려 일정상 이득입니다.

## 2. P1 — 런칭 전 반드시 해결

### P1-1. 주문 분할 어뷰징이 그대로 비용이 됨

5만원어치를 살 고객이 2만원 × 2건 + 1만원으로 쪼개면 뽑기가 1회에서 2회가 됩니다.
**무료배송 임계값이 2만원 이하라면 고객은 손해가 전혀 없고**, 텐바이텐만 출고비
2,940원 × 추가 건수를 부담합니다.

민감도 분석: 분할 유발률이 0% → 20%로 가면 (2만↑ 비중 50% 기준) 월 1,730만원 →
3,700만원으로 **2.1배**가 됩니다.

> **필수**: 무료배송 임계값 확인 → 뽑기 임계값을 무료배송 임계값보다 **높게** 설정.
> 그리고 1인 발급 상한(월 5회) 도입.

### P1-1a. 다만, 계단식 단가에는 역전 구간이 있음 (반드시 실측 확인)

출고 단가가 계단식이라 **건수가 늘면 총액이 오히려 줄어드는 구간**이 존재합니다.

| 구간 | 직전 최대 총액 | 다음 티어 진입 총액 | 무차별점 |
|---|---:|---:|---:|
| 0~19,999건 @ 2,940원 | 58,797,060원 | **51,800,000원** (20,000건 @2,590원) | **17,619건** |
| 20,000~24,999건 @ 2,590원 | 64,747,410원 | 59,500,000원 (25,000건 @2,380원) | 22,973건 |

**월 처리량이 17,620건을 이미 넘겼다면**, 분할 주문으로 20,000건을 돌파하는 것이
출고비 총액을 **약 700만원 낮춥니다.** 반대로 17,619건 이하라면 분할은 순수 손실입니다.

현재 공식 수치는 "월 10,000~20,000건"으로 이 무차별점을 걸치고 있습니다.
**실측 월 출고 건수 확인이 P1-1의 결론을 뒤집을 수 있습니다.** (Gate 1에 포함)

### P1-2. 미전달 사은품 — "꽝 없음" 광고와 충돌 + 충당부채

"다음 주문 때 동봉"은 다음 주문이 있어야 성립합니다. 유효기간 내 재주문이 없으면
사은품은 전달되지 않습니다.

| 유효기간 내 재주문율 | 월 미전달 건수 | 발급 대비 미전달 |
|---:|---:|---:|
| 20% | 3,481건 | **44.2%** |
| 30% | 3,046건 | 38.7% |
| 45% | 2,393건 | 30.4% |
| 60% | 1,740건 | 22.1% |
| 80% | 870건 | 11.1% |

재주문율이 낮은 현실적 구간에서 **발급의 30~44%가 전달되지 않습니다.** "꽝은 없다"고
광고한 상태에서 이 수치는 두 가지 문제를 만듭니다.

1. **표시광고 리스크** — 실제 수령률이 낮은데 "꽝 없음"을 전면에 쓰면 기만적 표시광고
   소지가 있습니다. **단정하지 않겠습니다. 법무 검토 필수 항목입니다.**
2. **회계** — 미지급 사은품은 회계상 부채입니다. 유효기간이 없으면 무한 누적됩니다.

> **수정 방향**: 유효기간 명시(90일 권장) + 만료 전 알림 + "유효기간 내 재주문 시
> 동봉"이라는 조건을 **뽑기 화면에서 사전 고지**. 미전달분은 포인트 자동 전환으로
> 처리하면 광고 리스크와 부채를 동시에 정리할 수 있습니다.

### P1-3. 재고와 확률이 연동되지 않음

재고가 0인 사은품이 뽑히면 어떻게 됩니까. 뽑기 확률 테이블은 **실시간 가용재고에
연동**되어야 하고, 재고 소진 시 해당 상품은 풀에서 자동 제외돼야 합니다. 이게 없으면
"당첨됐는데 품절입니다" CS가 발생하고 이건 P1-2보다 심각한 광고 이슈입니다.

### P1-4. 확률 표기

게임법상 확률형 아이템 규제는 게임에 적용되며 이커머스 랜덤 사은품에 직접 적용되지는
않습니다. 다만 규제 방향과 소비자 분쟁 예방 차원에서 **확률 자율 표기를 권장**합니다.
적용 범위 판단은 **법무 검토 항목**입니다.

### P1-5. CS 부하 및 조회 기능

"내 사은품 어디 갔어요"는 확실히 옵니다. **마이페이지에 뽑기 이력 / 미수령 사은품 목록
/ 유효기간 / 예상 동봉 시점**이 없으면 CS가 전부 받아냅니다. CS 인입 예상치를 산정하고
런칭 전에 조회 화면을 확보해야 합니다.

## 3. P2 — 개선 권고

- **네이밍**: 꽝이 없으면 "뽑기"가 아니라 "랜덤 사은품"입니다. "뽑기"는 고객에게 고가
  경품 기대를 만들고, 500~2,000원짜리 사은품이 나오면 기대 배반이 됩니다.
- **사은품 SKU 운영비**: 바코드 부착 100원/UNIT + 포천 센터 보관 공간. 이전 대상 재고가
  늘어나는 것이기도 합니다(P0-5).
- **박스 사이즈**: 동봉으로 박스 등급이 올라가면 택배 단가가 바뀔 수 있습니다. 사은품
  최대 부피 규격을 사전에 못 박아야 합니다.

## 4. 재설계 권고안

원안의 좋은 부분(구매 직후 보상, 다음 주문 동봉이라는 재구매 훅)은 살리고 무너지는
부분만 들어냈습니다.

| 항목 | 원안 | 권고안 |
|---|---|---|
| 임계값 | 2만원 이상 | **무료배송 임계값보다 높게** 설정 (실측 후 확정) |
| 발급 시점 | 불명확 | 결제완료 즉시 발급 / **출고는 구매확정 후** |
| 기준액 | 불명확 | 쿠폰·포인트 차감 후 **실결제 상품금액**, 배송비 제외 |
| 발급 상한 | 없음 | **1인 월 5회** |
| 결과 | 꽝 없음 + 수령 거절 가능 | 꽝 없음 + **거절 대신 포인트 전환 / 재뽑기 1회** |
| 수령 방식 | 동봉 / 모아서 받기 | **동봉 전용.** 모아받기는 3개 이상 + 배송비 고객부담 시에만 |
| 유효기간 | 없음 | **90일**, 만료 전 알림, 만료 시 포인트 자동 전환 |
| 노출 대상 | 전체 | **자사 물류 출고 이력 있는 주문** 우선 (Gate 0 결과 반영) |
| 런칭 시점 | 미정 | **물류 안정화 완료 후 = 2026년 10월** |

### 권고안의 경제성

"모아서 받기"를 제거한 것만으로:

| | 원안 | 동봉 전용 |
|---|---:|---:|
| 월 총비용 | 22,196,634원 | **11,911,688원** (▼46%) |
| 뽑기 1회당 | 2,819원 | **1,513원** |
| 손익분기 필요 주문 상승률 | 16.1% | **8.6%** |

8.6%도 결코 쉬운 숫자가 아닙니다. 그래서 A/B 테스트로 증분을 실측하기 전에는 전면
런칭하면 안 됩니다.

### 위험 구간

파라미터 조합 192개를 훑은 결과 **134개(70%)가 월 3,000만원을 초과**합니다. 참고로
물류센터 월차임이 34,385,000원입니다. **이 프로모션이 창고 임대료만큼 나갈 수 있는
설계**라는 뜻입니다. 상한선(월 예산 캡)과 자동 중단 조건을 반드시 걸어야 합니다.

## 5. 근거와 한계

**확정 근거** — 물류대행 단가표(2025년 기준, 부가세 별도), 월 처리량 10,000~20,000건,
물류센터 이전 일정. 출처: `10x10-company-info` 스킬.

**가정값 (검증 대상)** — 아래는 전부 추정이며 `01-validation-plan.md`에서 실측 대상입니다.

| 항목 | 가정값 | 근거 |
|---|---|---|
| 택배 단가 | 2,500원/BOX | 계약서에 없음. 업계 통상 대량계약가 |
| 기여이익률 | 25% | 마켓플레이스 위탁 수수료 추정 |
| AOV | 35,000원 | 추정 |
| 2만원 이상 주문 비중 | 50% | 추정 |
| 재주문율(90일) | 45% | 추정 |
| 거절률 | 15% | 추정 |
| 모아받기 선택률 | 35% | 추정 |

**직접 확인하지 못한 것** — 이 세션에서는 Superset/DB에 접근할 수 없었습니다. 위
가정값은 계산 모델의 입력일 뿐 실측이 아닙니다. `queries/` 의 SQL로 실측한 뒤
`tools/raffle_model.py`의 파라미터를 교체해 재실행하면 결론이 갱신됩니다.

재현: `python3 tools/raffle_model.py`
