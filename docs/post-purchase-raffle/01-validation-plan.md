# 구매 후 뽑기 — 검증 플랜

작성일: 2026-08-11
전제: `00-scenario-review.md`의 P0 5건이 미해소 상태이므로, 본 플랜은 **원안이 아니라
재설계 권고안(§4)을 검증 대상**으로 삼는다.

---

## 설계 원칙

**통과기준을 데이터보다 먼저 못 박는다.** 숫자를 본 뒤에 기준을 정하면 무슨 결과가
나와도 "할 만하다"는 결론이 나옵니다. 아래 모든 기준치는 **사전등록(pre-registered)**
이며, 실측 후 기준을 완화하려면 별도 승인 기록을 남깁니다.

**게이트는 순차적이고, 앞 게이트 탈락 시 뒤는 실행하지 않습니다.** Gate 0이 떨어지면
개발 착수 자체를 하지 않습니다. 가장 싸게 죽일 수 있는 순서로 배치했습니다.

**각 게이트는 KILL 조건을 명시합니다.** "재검토"가 아니라 중단입니다.

## Gate 0 — 동봉 실행 가능성 (KILL GATE)

시나리오 전체가 "다음 주문에 동봉"이라는 한 문장 위에 서 있습니다. 텐바이텐은 위탁
마켓플레이스이므로 **판매자 직배송 주문에는 동봉할 수 없습니다.** 이 비율을 모르는
채로는 다른 어떤 검증도 의미가 없습니다.

**핵심 질문**: 자사 물류센터(포천)에서 출고되는 주문의 비중은 얼마이고, 뽑기를 받은
고객의 *다음* 주문이 자사 물류 출고일 확률은 얼마인가?

**측정**
- Q0-1: 최근 6개월 전체 주문 대비 자사 물류센터 출고 주문 비중
- Q0-2: 2만원 이상 주문 고객의 다음 주문 중 자사 물류 출고 비중 (= 실질 동봉 가능률)
- Q0-3: 자사 물류 출고 + 판매자 직배송이 한 주문에 섞이는 비율

**사전등록 통과기준**

| 결과 | 판정 | 조치 |
|---|---|---|
| 동봉 가능률 ≥ 60% | PASS | G1 진행 |
| 40% ~ 60% | 조건부 | 자사 물류 출고 이력 고객으로 **대상 한정** 후 G1 |
| < 40% | **KILL** | 시나리오 폐기. 동봉 없는 별도 프로모션으로 전환 검토 |

**KILL 근거**: 동봉 가능률이 40% 미만이면 나머지 60%는 전부 "모아서 별도 배송"으로
흘러갑니다. 그 경로의 단위비용은 개당 7,040원이고, 어떤 파라미터에서도 회수되지
않습니다(`00-scenario-review.md` P0-2).

**추가 확인 (엔지니어링)**: 출고 시점에 회원의 미수령 사은품을 조회해 피킹리스트에
합류시키는 **Webadmin 연동이 가능한가**. 플러스에이컴퍼니에 기술 확인 필요. 불가하면
동봉 자체가 성립하지 않으므로 이것도 KILL 조건입니다.

## Gate 1 — 모델 가정 실측

`tools/raffle_model.py`의 입력값 중 추정치를 실측으로 교체합니다.

| ID | 측정 항목 | 현재 가정 | 사전등록 기준 | 실패 시 |
|---|---|---|---|---|
| Q1-1 | 2만원 이상 주문 비중 | 50% | 참고값 (KILL 없음) | 모델 갱신 |
| Q1-2 | **무료배송 임계값** | 미상 | 뽑기 임계값 > 무배 임계값 | 뽑기 임계값 상향 |
| Q1-3 | 1.5만~2만원 주문 비중 | 미상 | ≥ 8%면 상향 여력 있음 | 임계값 재설정 |
| Q1-4 | 90일 내 재주문율 | 45% | **≥ 35%** | < 35%면 유효기간 연장 또는 포인트 전환 기본값화 |
| Q1-5 | **월 실측 출고 건수** | 15,000건 | 17,619건 대비 위/아래 판정 | P1-1 결론 반전 여부 확정 |
| Q1-6 | 주문 취소·반품률 | 미상 | 참고값 | 회수 정책 설계 반영 |
| Q1-7 | AOV / 기여이익률 | 35,000원 / 25% | 재무 확인 | 손익분기 재계산 |

**Q1-5가 특히 중요합니다.** 월 출고가 17,620건을 넘겼다면 주문 분할은 출고비 총액을
오히려 낮춥니다(계단식 단가 역전). 이 경우 P1-1의 "분할 어뷰징 방어" 우선순위가
내려갑니다. 넘지 못했다면 분할은 순수 손실이고 상한 정책이 필수가 됩니다.

**Gate 1 종합 KILL 조건**: 실측값을 넣고 재실행했을 때 **동봉 전용 설계의 월 총비용이
2,000만원을 초과**하면 중단하고 임계값·사은품 원가를 재설계합니다.

쿼리: `queries/` 참조. **주의 — 주문 테이블 스키마는 이 세션에서 검증되지 않았습니다.
컬럼명은 실제 스키마 확인 후 수정 필요합니다.**

## Gate 2 — 단위경제 확정

**입력**: G1 실측값
**작업**
1. `tools/raffle_model.py` 파라미터 교체 후 재실행
2. 플러스에이컴퍼니에 **신규 공정 단가 견적** 요청
   - 사은품 동봉 작업이 기존 "정합작업 1,000원/세트"로 청구되는지, 별도 신설인지
   - 사은품 SKU 보관료 / 바코드 부착비
   - 미수령 사은품 조회·합류 로직의 Webadmin 개발 비용
   - **이전 후 신규 센터 단가 재협상과 함께 묶어서 협상할 것** (이전 프로젝트 Phase 2
     에서 단가 재협상이 예정되어 있으므로 레버리지가 있음)
3. 택배 실계약 단가 확인 (모델은 2,500원 가정)

**사전등록 통과기준**

| 지표 | 기준 | 판정 |
|---|---|---|
| 뽑기 1회당 총비용 | ≤ 1,800원 | 초과 시 사은품 원가 하향 또는 임계값 상향 |
| 손익분기 필요 주문 상승률 | **≤ 10%** | 초과 시 **KILL** |
| 월 비용 상한(캡) | 설정 필수 | 캡 없으면 진행 불가 |

**KILL 근거**: 손익분기 상승률이 10%를 넘으면, 프로모션이 성공해도 본전입니다.
사은품 프로모션의 현실적 주문 상승 기여는 한 자릿수 중반이 상한입니다.

## Gate 3 — 물류 파일럿 (수기, 100건)

시스템 개발 **전에** 창고가 실제로 이걸 할 수 있는지 손으로 확인합니다. 개발 후에
"창고에서 안 된다"가 나오는 게 최악의 시나리오입니다.

**방법**: 특정 세그먼트 100명에게 수기로 사은품 지급 → 다음 주문 시 수기 동봉

**측정 및 사전등록 기준**

| 지표 | 기준 | KILL |
|---|---|---|
| 동봉 성공률 (지시 대비 실제 동봉) | **≥ 95%** | < 90% |
| 동봉 누락·오배송 발생 | ≤ 2건/100건 | > 5건 |
| 출고 처리 지연 (평시 대비) | ≤ +10% | > +25% |
| 박스 등급 상향 발생률 | ≤ 10% | 참고값 |
| CS 인입 (100건당) | ≤ 5건 | > 15건 |

**실행 시점 제약**: 물류센터 **이전 안정화 완료 이후**에만 실행합니다(9월 둘째주 이후).
이전 중 파일럿은 이전 리스크를 키우고, 결과도 오염돼서 아무것도 알 수 없습니다.

## Gate 4 — A/B 테스트 (증분 검증)

여기가 진짜 검증입니다. 앞의 게이트는 전부 "비용이 얼마인가"를 봤고, 여기서 처음으로
**"수익이 늘긴 하는가"**를 봅니다.

**설계**
- 대조군 / 실험군 무작위 배정 50:50
- 기간 **4주** (재구매 주기를 고려하면 8주가 이상적이나, 4주 시점 중간 판정)
- 실험군에만 뽑기 노출

**1차 지표 (사전등록)**

| 지표 | 정의 | 통과기준 |
|---|---|---|
| **주문 건수 증분** | 실험군 인당 주문수 / 대조군 − 1 | **≥ +8%, p < 0.05** |
| **GMV 증분** | 실험군 인당 GMV / 대조군 − 1 | ≥ +5% |
| 90일 재구매율 증분 | 실험군 − 대조군 | ≥ +3%p |

**가드레일 지표 (하나라도 위반 시 즉시 중단)**

| 지표 | 한계선 |
|---|---|
| 주문당 평균 금액(AOV) | 대조군 대비 **−5% 초과 하락 금지** (분할 주문 감지) |
| 인당 주문 건수 이상치 | 상위 1% 유저의 주문 분할 패턴 발생 시 조사 |
| 취소·반품률 | 대조군 대비 +2%p 초과 금지 (뽑기 후 취소 어뷰징) |
| 실제 월 비용 | G2에서 설정한 예산 캡 초과 시 즉시 중단 |
| CS 인입 | 프로모션 관련 문의가 전체 인입의 3% 초과 금지 |

**AOV 가드레일이 핵심입니다.** 주문 건수만 보면 분할 주문도 "성공"으로 보입니다.
건수는 늘고 AOV가 떨어지면 그건 증분이 아니라 **같은 매출을 더 비싼 물류비로 나눠
치른 것**입니다.

**사전등록 판정 규칙**
- 주문 건수 증분이 +8% 미만이면 **KILL**. "조금 더 돌려보자"는 하지 않습니다.
- 증분이 +8% 이상이어도 AOV 가드레일 위반 시 **KILL**.
- 둘 다 통과해야 G5.

**표본 크기**: 기준 전환율과 최소검출효과(+8%)로 사전 산출하여 검정력 80% 확보.
표본이 부족하면 기간을 늘리되 **기준치는 낮추지 않습니다.**

## Gate 5 — 단계적 확대

G4 통과 후에도 한 번에 열지 않습니다. 파일럿 규모에서 성립한 경제성이 전량에서
깨지는 일은 흔합니다.

| 단계 | 노출 | 기간 | 중단 조건 |
|---|---|---|---|
| 5-1 | 10% | 2주 | 예산 캡 80% 도달 / 동봉 성공률 < 95% |
| 5-2 | 30% | 2주 | 동일 |
| 5-3 | 60% | 2주 | 동일 |
| 5-4 | 100% | 상시 | 월간 리뷰 |

**상시 운영 조건 (전부 필수)**
- 월 예산 캡 + 캡 도달 시 **자동 중단** 스위치
- 사은품 재고 실시간 연동 (재고 0 → 뽑기 풀에서 자동 제외)
- 마이페이지 뽑기 이력 / 미수령 목록 / 유효기간 조회
- 미수령 사은품 부채 월간 리포트
- 유효기간 만료 30일 전 알림 → 만료 시 포인트 자동 전환

## 병행 트랙 — 법무 검토 (게이트와 무관하게 즉시 착수)

**단정하지 않겠습니다. 아래는 전부 법무 확인 항목입니다.**

| 항목 | 확인 내용 |
|---|---|
| "꽝 없음" 표기 | 실제 미전달률 30~44% 상황에서 표시광고법상 기만적 표시 소지 |
| 확률 표기 의무 | 게임법상 확률형 아이템 규제의 이커머스 랜덤 사은품 적용 여부 |
| 경품 규제 | 경품류 제공 관련 현행 규제의 적용 범위 및 가액 한도 |
| 약관 | 유효기간, 소멸, 취소 시 회수, 포인트 전환에 대한 사전 고지 요건 |
| 회계 | 미지급 사은품의 충당부채 인식 기준 (재무팀 병행) |

법무 결론이 "꽝 없음 표기 불가"로 나오면 **커뮤니케이션 전면 재설계**가 필요하므로,
G4 착수 전에 결론이 나와 있어야 합니다.

## 이 플랜이 죽이려는 것

정직하게 말하면, **이 플랜은 시나리오를 통과시키기 위한 것이 아니라 싸게 죽이기 위한
것입니다.** 게이트를 비용이 낮은 순서로 배치했고, KILL 조건을 앞쪽에 몰아두었습니다.

- G0에서 죽으면 손실 0
- G2에서 죽으면 손실 0
- G4까지 가서 죽으면 약 1,000만원

가장 나쁜 결과는 검증 없이 전면 런칭한 뒤 월 3,000만원을 태우면서(파라미터 조합의
70%가 이 구간입니다) 물류센터 이전 안정화까지 흔드는 것입니다. 그것에 비하면 위 순서는
저렴합니다.
