# dev

사내 서비스 작업용 레포입니다.

| 디렉토리 | 설명 |
|---|---|
| [`biz-admin/`](./biz-admin) | PB 트렌드 허브 프로토타입. 실제 biz-admin(Bitbucket `backpackr/business-operation-admin`)의 트렌드 HUB에 넣기 전 검증용 |

## 실행

```bash
cd biz-admin
npm install
npm start   # http://localhost:3000
```
